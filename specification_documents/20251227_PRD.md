# Astro + GitHub Pages 工程 Feature 清單（初版）

## 1️⃣ 核心網站架構

| Feature   | 說明                                | 技術選型 / 備註                            |
| --------- | --------------------------------- | ------------------------------------ |
| 靜態網站      | 所有文章與頁面皆生成靜態 HTML                 | Astro                                |
| 部署        | 免費、穩定、可自訂網域                       | GitHub Pages                         |
| 自訂網域      | 自己購買，綁定 repo                      | DNS A / CNAME                        |
| HTTPS     | GitHub Pages 自動                   | 無需額外配置                               |
| SEO 基礎    | sitemap.xml / meta / OG / Twitter | Astro SEO 插件或自訂 component            |
| Analytics | 全站流量統計                            | Cloudflare Web Analytics / Plausible |

## 4️⃣ 按讚與分享功能

### 4.1 分享按鈕（靜態實現）

* 功能：

  * 分享到 Facebook / Twitter / Line / WhatsApp
  * 分享時抓文章 title + URL
* 技術：

  * HTML `<a>` + JS snippet
  * Astro component

```astro
<!-- ShareButtons.astro -->
<div class="share-buttons">
  <a href={`https://twitter.com/intent/tweet?url=${url}&text=${title}`} target="_blank">Twitter</a>
  <a href={`https://www.facebook.com/sharer/sharer.php?u=${url}`} target="_blank">Facebook</a>
</div>
```

### 4.2 按讚（Client-side 無 backend）

#### 方案 A：本地 storage + JS

* 只會在該使用者瀏覽器生效
* 不同步
* 技術：localStorage + JS
* 優點：零 backend，簡單
* 缺點：無法統計全球按讚數

#### 方案 B：第三方 like service / badge（推薦）

* 如 [Utterances-like](https://utteranc.es/) / GitHub Reaction 方案
* 或者未來用 **Cloudflare Worker + KV** 記錄按讚
* 初期可先顯示「按讚按鈕，但數字不顯示」

> 對思想型網站來說，建議初期只放按鈕，**數字可以後面再加**。
